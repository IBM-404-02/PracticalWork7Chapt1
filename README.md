# Отладка консольного приложения «Галактики»

Проект демонстрирует использование инструментов отладки Visual Studio на примере приложения, которое работает со списком объектов класса `Galaxy`.

## Использованные способы отладки

- **Точки останова (Breakpoints)** — поставлены на строке создания списка галактик и внутри цикла `foreach` для остановки на каждой итерации.
- **Шаг с обходом (Step Over, F10)** — последовательное прохождение строк цикла без захода в свойства-геттеры.
- **Шаг с заходом (Step Into, F11)** — заход в свойство `MyGType` для проверки логики `switch`-конструкции.
- **Окно «Автозапуск» (Autos)** — автоматический показ переменных `theGalaxy`, `MainType`, `SubType` в текущем контексте.
- **Окно «Локальные» (Locals)** — просмотр всех переменных текущей области, включая поля объекта `Galaxy`.
- **Подсказки по данным (DataTips)** — наведение курсора на `theGalaxies` для разворачивания списка и просмотра содержимого.
- **Условная точка останова (Conditional Breakpoint)** — срабатывание только при условии `theGalaxy.Name == "Milky Way"`.
- **Изменение значений переменных** в окне «Локальные» во время отладки для проверки разных сценариев.
