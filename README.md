# Отладка консольного приложения «Буквы»

Проект-туториал по отладчику Visual Studio на примере программы, которая по одной букве выводит имя в консоль с задержкой.

## Использованные способы отладки

- **Точки останова (Breakpoints)** — установлены на строках цикла `for` для остановки на каждой итерации добавления буквы.
- **Запуск с отладчиком (F5)** — запуск приложения в режиме Debug для активации всех средств отладки.
- **Шаг с обходом (Step Over, F10)** — пошаговое прохождение строк внутри цикла.
- **Шаг с заходом (Step Into, F11)** — проверка работы `Console.WriteLine` и обращения к индексу строки `name[i]`.
- **Выход (Step Out, Shift+F11)** — выход из метода `doWork()` обратно в `Main()`.
- **Окно «Локальные» (Locals)** — наблюдение за изменением `letters`, `i`, `name` на каждой итерации.
- **Подсказки по данным (DataTips)** — просмотр текущего значения `letters` наведением курсора.
- **Окно «Контрольные значения» (Watch)** — добавление выражения `name.Length` для отслеживания.
- **Окно вывода (Output)** — просмотр результатов `Console.WriteLine` и сообщений отладчика.
- **Перезапуск (Restart, Ctrl+Shift+F5)** — повторный запуск отладки после внесения изменений.
