# Отладка консольного приложения «Фибоначчи»

Проект для отработки навыков отладки в Microsoft Visual Studio. Программа вычисляет n-ое число последовательности Фибоначчи.

## Использованные способы отладки

- **Точки останова (Breakpoints)** — установка красных точек слева от номера строки для приостановки выполнения программы на конкретном операторе.
- **Шаг с заходом (Step Into, F11)** — переход внутрь вызываемой функции `Fibonacci()` для построчного выполнения её тела.
- **Шаг с обходом (Step Over, F10)** — выполнение строки целиком без захода внутрь функции.
- **Окно «Локальные» (Locals)** — наблюдение за значениями переменных `n1`, `n2`, `sum`, `i` в текущей области выполнения цикла `for`.
- **Окно «Контрольные значения» (Watch)** — добавление переменной `sum` для отслеживания её изменения на каждой итерации.
- **Подсказки по данным (DataTips)** — наведение курсора на переменную в редакторе для просмотра её текущего значения.
- **Стек вызовов (Call Stack)** — просмотр последовательности вызовов `Main → Fibonacci`.
